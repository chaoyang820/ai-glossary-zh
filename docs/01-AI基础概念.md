# 01｜AI 基础概念

[← 返回目录](../README.md)

| 英文 | 中文 | 作用 |
|---|---|---|
| Artificial Intelligence (AI) | 人工智能 | 让计算机完成感知、理解、推理、决策或生成等通常需要人类智能的任务。 |
| Machine Learning (ML) | 机器学习 | 让系统从数据中学习规律，而不是为每条规则手工编程。 |
| Deep Learning | 深度学习 | 使用多层神经网络学习复杂模式，是现代大模型的基础。 |
| Foundation Model | 基础模型 | 在大规模通用数据上预训练，可适配文本、图像、代码等多种下游任务。 |
| Large Language Model (LLM) | 大语言模型 | 以大量文本和代码训练，按上下文预测并生成 token。 |
| Generative AI | 生成式 AI | 生成文本、代码、图片、音频或视频等新内容的 AI。 |
| Transformer | Transformer 架构 / 变换器 | 依靠注意力机制处理序列，是主流语言模型的核心架构。 |
| Attention | 注意力机制 | 动态判断输入中哪些部分对当前计算最重要。 |
| Parameter | 参数 | 模型训练得到的数值权重；参数量常用于粗略描述模型规模。 |
| Training | 训练 | 用数据和优化算法调整参数，使模型学会目标能力。 |
| Pre-training | 预训练 | 在海量通用数据上进行初始训练，获得基础知识和语言能力。 |
| Post-training | 后训练 | 在预训练后用指令数据、偏好数据或强化学习改善可用性和行为。 |
| Inference | 推理 | 已训练模型根据输入生成结果的运行阶段。 |
| Token | 词元 | 模型切分和处理文本的基本单位，影响上下文容量、速度和费用。 |
| Tokenization | 词元化 | 把文本转换成 token 编号序列的过程。 |
| Prompt | 提示词 | 发送给模型的任务说明、问题、示例或上下文。 |
| System prompt | 系统提示词 | 设定模型身份、规则和高层行为的指令，优先级通常高于普通用户消息。 |
| Completion | 补全 / 生成结果 | 模型根据输入继续生成的内容。 |
| Temperature | 温度 | 控制输出随机性；低值更稳定，高值通常更多样。 |
| Top-p | 核采样阈值 | 只从累计概率达到阈值的候选 token 中采样，用于调节多样性。 |
| Modality | 模态 | 信息的形式，如文本、图像、音频、视频或传感器数据。 |
| Multimodal | 多模态 | 模型能够理解或生成两种以上模态。 |
| Native multimodality | 原生多模态 | 在统一模型架构中直接学习和处理多种模态。 |
| Zero-shot | 零样本 | 不给示例，仅凭任务说明让模型完成任务。 |
| Few-shot | 少样本 | 在提示中给少量示例，帮助模型模仿格式或规律。 |
| Grounding | 依据绑定 / 有据生成 | 让回答建立在指定资料、检索结果或真实环境状态上。 |
| Hallucination | 幻觉 | 模型生成看似合理但事实错误、来源不存在或不受证据支持的内容。 |
| Open weights | 开放权重 | 公开可下载的模型权重；不一定同时开源训练数据和训练代码。 |
| Closed model | 闭源模型 | 权重不公开，通常通过产品或 API 使用。 |
