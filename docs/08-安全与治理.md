# 08｜安全与治理
[← 返回目录](../README.md)

| 英文 | 中文 | 作用 |
|---|---|---|
| AI safety | AI 安全 | 降低 AI 对用户和组织的风险。 |
| Guardrails | 防护栏 | 在输入、输出和执行周围添加规则。 |
| Prompt injection | 提示词注入 | 恶意内容诱导智能体忽略原指令。 |
| Jailbreak | 越狱提示 | 试图绕过安全限制的输入。 |
| Indirect prompt injection | 间接提示词注入 | 攻击指令藏在网页或文档中。 |
| Data exfiltration | 数据外泄 | 敏感信息被未授权发送。 |
| Least privilege | 最小权限 | 只授予完成任务所需权限。 |
| Sandbox | 沙箱 | 隔离环境并限制权限。 |
| Allowlist | 允许列表 | 只允许预先认可的操作。 |
| Human in the loop | 人在回路 | 关键点由人工审批或接管。 |
| Approval mode | 审批模式 | 规定哪些操作必须确认。 |
| Red teaming | 红队测试 | 模拟攻击者寻找弱点。 |
| Content moderation | 内容审核 | 识别有害或不合规内容。 |
| PII | 个人身份信息 | 可识别个人的信息。 |
| Data residency | 数据驻留 | 规定数据存储地区。 |
| Data retention | 数据保留 | 定义数据保存多久。 |
| Audit log | 审计日志 | 记录谁执行了什么操作。 |
| Governance | 治理 | 用政策和流程管理 AI。 |
| Model card | 模型卡 | 说明模型用途、限制和风险。 |
| Supply-chain risk | 供应链风险 | 来自第三方模型、插件或数据的风险。 |
