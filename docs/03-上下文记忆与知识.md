# 03｜上下文、记忆与知识
[← 返回目录](../README.md)

| 英文 | 中文 | 作用 |
|---|---|---|
| Context | 上下文 | 模型当前能看到的全部信息。 |
| Context window | 上下文窗口 | 一次推理可容纳的 token 上限。 |
| Context engineering | 上下文工程 | 选择、组织、压缩和更新模型所见信息。 |
| Prompt engineering | 提示工程 | 设计指令、示例和输出要求。 |
| Context bloat | 上下文膨胀 | 信息过多造成成本和干扰。 |
| Context rot | 上下文腐化 | 上下文变长后关键信息利用能力下降。 |
| Compaction | 上下文压缩 | 将长记录压缩为摘要和关键状态。 |
| Memory | 记忆 | 保存跨轮次或跨会话的信息。 |
| Short-term memory | 短期记忆 | 当前任务的临时状态。 |
| Long-term memory | 长期记忆 | 跨会话持久保存的信息。 |
| Episodic memory | 情景记忆 | 保存过去任务和事件。 |
| Semantic memory | 语义记忆 | 保存事实、概念和关系。 |
| RAG | 检索增强生成 | 回答前检索外部资料。 |
| Embedding | 嵌入向量 | 将内容转换为数值向量。 |
| Vector database | 向量数据库 | 存储向量并支持相似度搜索。 |
| Semantic search | 语义搜索 | 按含义而非纯关键词匹配。 |
| Hybrid search | 混合搜索 | 结合关键词和向量搜索。 |
| Reranker | 重排模型 | 对检索结果重新评分。 |
| Chunking | 分块 | 将长文档切成便于索引的小段。 |
| GraphRAG | 图增强 RAG | 将图结构检索与生成结合。 |
