# 10｜生成式媒体
[← 返回目录](../README.md)

| 英文 | 中文 | 作用 |
|---|---|---|
| Text-to-image | 文生图 | 根据文字描述生成图片。 |
| Image-to-image | 图生图 | 以输入图片生成新图。 |
| Inpainting | 局部重绘 | 重新生成指定图片区域。 |
| Outpainting | 扩图 | 在原图边界外生成内容。 |
| Diffusion model | 扩散模型 | 从噪声逐步还原内容。 |
| Latent space | 潜空间 | 模型压缩表示特征的空间。 |
| Seed | 随机种子 | 控制随机性以便复现。 |
| Negative prompt | 负向提示词 | 描述希望避免的元素。 |
| ControlNet | 条件控制网络 | 用姿态、边缘等约束生成。 |
| LoRA | 低秩适配 | 用少量参数微调风格。 |
| Text-to-video | 文生视频 | 根据文字生成视频。 |
| Image-to-video | 图生视频 | 让静态图片产生运动。 |
| Frame consistency | 帧间一致性 | 保持角色和场景跨帧稳定。 |
| Text-to-speech | 文本转语音 | 将文字合成为语音。 |
| Speech-to-text | 语音转文字 | 将语音转写为文字。 |
| Voice cloning | 声音克隆 | 学习特定说话人的音色。 |
| VAD | 语音活动检测 | 判断何时有人讲话。 |
| Realtime API | 实时 API | 支持低延迟多模态交互。 |
| OCR | 光学字符识别 | 从图片中提取文字。 |
| VLM | 视觉语言模型 | 同时理解图像和文字。 |
| Visual grounding | 视觉定位 | 将文字概念对应到图像区域。 |
| Upscaling | 超分辨率放大 | 提升图片或视频清晰度。 |
| Watermarking | 水印标识 | 为生成内容加入来源标记。 |
| Deepfake | 深度伪造 | 高度逼真地合成人脸或声音。 |
