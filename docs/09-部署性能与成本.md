# 09｜部署、性能与成本
[← 返回目录](../README.md)

| 英文 | 中文 | 作用 |
|---|---|---|
| Model serving | 模型服务化 | 将模型部署为在线服务。 |
| Endpoint | 服务端点 | 客户端发送请求的地址。 |
| Throughput | 吞吐量 | 单位时间处理的请求或 token 数。 |
| Latency | 延迟 | 请求到响应所需时间。 |
| Tokens per second | 每秒 token 数 | 衡量持续生成速度。 |
| Batch inference | 批量推理 | 多个请求一起计算。 |
| Continuous batching | 连续批处理 | 动态组合在线请求。 |
| GPU | 图形处理器 | 大模型常用计算硬件。 |
| VRAM | 显存 | 存放权重和缓存的内存。 |
| KV cache | 键值缓存 | 缓存注意力结果避免重复计算。 |
| Prefix caching | 前缀缓存 | 对共同输入前缀复用缓存。 |
| Speculative decoding | 推测解码 | 小模型起草、大模型验证。 |
| Tensor parallelism | 张量并行 | 将计算分散到多个设备。 |
| Autoscaling | 自动扩缩容 | 根据流量调整实例。 |
| Cold start | 冷启动 | 首次加载模型的额外延迟。 |
| Edge AI | 边缘 AI | 在用户设备本地运行模型。 |
| Cloud inference | 云端推理 | 在远程数据中心运行模型。 |
| Cost per token | 每 token 成本 | 按输入输出 token 计算费用。 |
| TCO | 总拥有成本 | 算力、工程和运维总成本。 |
| SLA | 服务等级协议 | 对可用性和延迟的正式承诺。 |
