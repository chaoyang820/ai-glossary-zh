# 05｜AI 开发工程
[← 返回目录](../README.md)

| 英文 | 中文 | 作用 |
|---|---|---|
| API | 应用程序接口 | 让程序调用模型能力。 |
| SDK | 软件开发工具包 | 封装 API 和辅助方法。 |
| Responses API | 响应式 API | 面向智能体的统一模型接口。 |
| Structured outputs | 结构化输出 | 约束模型按固定结构返回。 |
| JSON Schema | JSON 模式 | 定义 JSON 字段和约束。 |
| Streaming | 流式输出 | 生成时持续返回 token 或事件。 |
| SSE | 服务器发送事件 | 向客户端持续推送事件。 |
| Async | 异步 | 启动任务后不阻塞等待。 |
| Webhook | 回调通知 | 事件发生时请求指定网址。 |
| Idempotency | 幂等性 | 重复请求不造成重复副作用。 |
| Retry | 重试 | 临时失败后再次执行。 |
| Rate limit | 速率限制 | 限制请求或 token 用量。 |
| Workflow | 工作流 | 串联模型、工具和业务系统。 |
| State machine | 状态机 | 用明确状态管理流程。 |
| Model routing | 模型路由 | 根据难度和成本选择模型。 |
| Fallback | 降级方案 | 失败时切换备用实现。 |
| Schema validation | 模式校验 | 检查输出是否符合结构。 |
| Semantic cache | 语义缓存 | 对相似请求复用答案。 |
| AI gateway | AI 网关 | 统一管理鉴权、路由和限流。 |
| LLMOps | 大模型运维 | 管理提示、模型、评测和部署。 |
