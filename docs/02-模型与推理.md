# 02｜模型与推理
[← 返回目录](../README.md)

| 英文 | 中文 | 作用 |
|---|---|---|
| Reasoning model | 推理模型 | 在回答前投入额外计算处理多步问题。 |
| Reasoning effort | 推理强度 | 调节推理计算，在质量、速度和成本间取舍。 |
| Test-time compute | 推理时计算 | 回答阶段增加思考、搜索或验证。 |
| Chain of Thought | 思维链 | 将复杂问题拆成中间推理步骤。 |
| Reflection | 反思 | 让模型检查结果、找出问题并修改。 |
| Planning | 规划 | 在行动前拆解目标和排列步骤。 |
| Mixture of Experts | 混合专家模型 | 每次只激活部分专家网络。 |
| Dense model | 稠密模型 | 每次推理大体激活全部参数。 |
| Small Language Model | 小语言模型 | 成本低、延迟短，适合端侧或明确任务。 |
| Frontier model | 前沿模型 | 当前能力处于行业领先水平的模型。 |
| Distillation | 蒸馏 | 用强模型训练较小模型。 |
| Fine-tuning | 微调 | 用领域数据继续训练模型。 |
| SFT | 监督微调 | 用输入与理想输出样本训练模型。 |
| RLHF | 基于人类反馈的强化学习 | 用人类偏好优化模型行为。 |
| RLAIF | 基于 AI 反馈的强化学习 | 使用 AI 生成或评价偏好信号。 |
| DPO | 直接偏好优化 | 直接用成对偏好数据优化模型。 |
| Alignment | 对齐 | 让模型符合人类意图和安全目标。 |
| Quantization | 量化 | 用低精度表示权重以减少显存。 |
| Pruning | 剪枝 | 删除影响较小的权重或结构。 |
| Synthetic data | 合成数据 | 由模型生成的训练或评测数据。 |
