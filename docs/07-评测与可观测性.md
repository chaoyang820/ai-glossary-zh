# 07｜评测与可观测性
[← 返回目录](../README.md)

| 英文 | 中文 | 作用 |
|---|---|---|
| Evals | 评测 | 衡量 AI 质量和回归。 |
| Benchmark | 基准测试 | 用统一任务比较模型。 |
| Grader | 评分器 | 自动判断输出是否满足标准。 |
| LLM-as-a-judge | 大模型裁判 | 用大模型评价回答。 |
| Golden answer | 标准答案 | 评测时用于对比的参考输出。 |
| Rubric | 评分量表 | 将质量要求拆成评分标准。 |
| Pass@k | k 次通过率 | k 个候选中至少一个正确的概率。 |
| Accuracy | 准确率 | 预测正确的样本占比。 |
| Precision | 精确率 | 判为正的结果中真正为正的比例。 |
| Recall | 召回率 | 真正为正的结果中被找出的比例。 |
| Groundedness | 有据性 | 回答是否得到资料支持。 |
| Faithfulness | 忠实度 | 内容是否忠于来源。 |
| Robustness | 鲁棒性 | 异常输入下仍稳定工作的能力。 |
| Regression | 回归退化 | 新版本使原本通过的场景变差。 |
| A/B test | A/B 测试 | 分组比较两个版本。 |
| Observability | 可观测性 | 用日志和指标理解系统行为。 |
| Tracing | 链路追踪 | 记录模型和工具调用过程。 |
| Telemetry | 遥测数据 | 系统运行时的日志和事件。 |
| TTFT | 首 token 时间 | 请求到首个 token 的时间。 |
| Success rate | 成功率 | 完成目标的任务占比。 |
