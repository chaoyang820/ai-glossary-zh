# 06｜AI 编程与工具
[← 返回目录](../README.md)

| 英文 | 中文 | 作用 |
|---|---|---|
| Vibe coding | 氛围编程 | 用自然语言描述想法，由 AI 生成和修改代码。 |
| Agentic coding | 智能体式编程 | AI 读取仓库、编辑文件、运行命令和测试。 |
| AI pair programmer | AI 结对程序员 | 人主导，AI 提供补全和建议。 |
| Code completion | 代码补全 | 预测当前位置后续代码。 |
| Inline edit | 行内编辑 | 用自然语言修改选中代码。 |
| Code review | 代码审查 | 检查缺陷、安全和可维护性。 |
| Repo-scale reasoning | 仓库级推理 | 跨文件理解架构和调用关系。 |
| Spec-driven development | 规格驱动开发 | 先写规格和验收任务再编码。 |
| Plan mode | 规划模式 | 先分析和制定方案。 |
| Diff | 差异 | 显示修改前后的变化。 |
| Patch | 补丁 | 描述一组文件增删改。 |
| AGENTS.md | 智能体项目说明文件 | 告诉智能体规范和测试方法。 |
| Codex | OpenAI 编程智能体 | 理解仓库并执行工程任务。 |
| Claude Code | Anthropic 编程智能体 | 在终端或 IDE 中处理代码。 |
| GitHub Copilot | GitHub AI 编程助手 | 提供补全、聊天和 agent。 |
| Gemini CLI | Google 命令行智能体 | 在终端处理代码任务。 |
| Cursor | AI 代码编辑器 | 以 AI 补全和 agent 为核心。 |
| Windsurf | AI 代码编辑器 | 提供代码理解和智能体开发。 |
| Cline | 开源编程智能体扩展 | 在编辑器中调用模型和工具。 |
| Aider | 终端 AI 结对编程工具 | 通过聊天修改 Git 仓库。 |
| Codebase indexing | 代码库索引 | 帮助 AI 检索相关代码。 |
| CI | 持续集成 | 自动运行构建、测试和检查。 |
