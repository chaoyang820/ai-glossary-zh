# 04｜Agent 与协议
[← 返回目录](../README.md)

| 英文 | 中文 | 作用 |
|---|---|---|
| Agent | 智能体 | 围绕目标自主规划并执行多步任务。 |
| Agentic AI | 智能体式 AI | 强调 AI 能行动和完成工作。 |
| Agent loop | 智能体循环 | 反复观察、推理、行动和检查。 |
| Agent harness | 智能体运行框架 | 管理工具、上下文、权限和执行。 |
| Subagent | 子智能体 | 由主智能体派出处理子任务。 |
| Multi-agent system | 多智能体系统 | 多个智能体分工协作。 |
| Orchestration | 编排 | 管理任务路由、状态和汇总。 |
| Handoff | 任务移交 | 将任务交给另一智能体或人工。 |
| Tool calling | 工具调用 | 让模型调用外部能力。 |
| MCP | 模型上下文协议 | 统一连接工具和数据源。 |
| MCP client | MCP 客户端 | 连接 MCP 服务并使用能力。 |
| MCP server | MCP 服务端 | 暴露工具、资源或提示。 |
| MCP tool | MCP 工具 | 可被模型调用的操作能力。 |
| MCP resource | MCP 资源 | 服务端提供的可读取数据。 |
| A2A | 智能体间协议 | 让不同智能体通信协作。 |
| Agent Card | 智能体名片 | 描述身份、技能、接口和安全要求。 |
| Agent Skills | 智能体技能 | 用 SKILL.md 和资源封装能力。 |
| Plugin | 插件 | 打包技能、连接器和配置。 |
| Connector | 连接器 | 将外部应用和数据接入 AI。 |
| Computer use | 计算机操作 | 通过屏幕、点击和输入操作软件。 |
